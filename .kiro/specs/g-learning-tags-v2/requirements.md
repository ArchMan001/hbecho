## 1. 引言

课程标签现在是**扁平一级**：`tags.name` 全局唯一，课程与标签多对多，学习中心只能按单个标签筛选（`g-learning-min` G-D14）。业务实际用的是四个维度（平台、板块、阶段、课程类型），目前只能把维度写进标签名（`平台-抖音`、`板块-直播`），筛选也无法按维度组合。

本 spec 把标签改为**两级**：一级是标签分类（可新增），二级是标签值；课程在同一个分类下可多选；学习中心按分类多选筛选。

## 2. 范围边界

### 2.1 做什么

1. 新增一级「标签分类」（可新增、可改名、空分类可删）；标签值挂在分类下；
2. 同一门课可在同一分类下选择多个标签值（例如平台 = 抖音 + 小红书）；
3. 标签管理页按分类分组维护；
4. 新建 / 编辑课程页按分类分组多选；
5. 学习中心筛选改为按分类多选：**同类 OR、跨类 AND**；
6. 现有扁平标签按「分类-值」前缀迁移，保留课程引用。

### 2.2 明确不做

| 不做 | 原因 |
|---|---|
| 标签合并 / 同义词治理 | 仍是已知风险；本切片只做层级，不扩大 |
| 课程在某个分类下必选 | 用户确认只要求「至少一个标签」；每个分类可空 |
| 分类排序拖拽 | 新分类追加在末尾；排序不在本轮 |
| 标签构成可见性 | 标签仍不参与品牌 / 级别可见性 |
| 标签使用统计报表 | 只在标签管理显示引用课程数 |
| 多语言 / 标签颜色 | 不在 1.0 |

## 6. 需求条目

### TL-1 分类管理

系统 SHALL 允许持有 `learning.tag.manage` 的超管新增、改名、删除空分类；其他角色 SHALL NOT。

- `[自动]` 非超管调用分类写操作 → 403；
- `[自动]` 分类名 1–32 字符、去空白、全局唯一；重复 → 409；
- `[自动]` 删除仍有标签的分类 → 409，返回标签数；空分类删除成功；
- `[自动]` 改名分类不影响标签与课程引用；
- `[自动]` 分类增改删写审计事件。

### TL-2 标签值管理

标签 SHALL 属于且仅属于一个分类；同一分类内名称唯一，不同分类可同名。

- `[自动]` 新建标签必须给 `categoryId`；分类不存在 → 404；
- `[自动]` 同一分类内重复名 → 409；跨分类同名成功；
- `[自动]` 改名只改当前标签；删除被课程引用 → 409 并返回引用数（沿用现状）；
- `[自动]` 标签列表返回 `categoryId`、`categoryName`，可附引用课程数。

### TL-3 课程标签选择

课程 SHALL 可在同一分类下选择多个标签；整门课 SHALL 至少一个标签。

- `[自动]` 提交 0 个标签 → 400（沿用 G-D21）；
- `[自动]` 提交同一分类下多个标签 → 保存成功，全部建立 `course_tags`；
- `[自动]` 提交不存在或已删除的标签 → 400；
- `[自动]` 编辑课程时替换标签集合按现有语义整组替换。

### TL-4 学习中心筛选

筛选 SHALL 支持多标签，同类 OR、跨类 AND。

- `[自动]` 选择平台=抖音、板块=直播 → 返回同时命中两个分类的课程；
- `[自动]` 选择平台=抖音、平台=小红书 → 返回命中任一平台的课程；
- `[自动]` 未选标签 → 不按标签收窄；
- `[自动]` 重复 `tag` 参数不再报 `multiple_tags`；非法 ID → 400；
- `[自动]` 结果按现有排序与分页，标题搜索与「只看在学」可叠加。

### TL-5 迁移

现有扁平标签 SHALL 迁移为分类 + 标签值，课程引用不丢。

- `[环境]` 在测试 ECS 的库副本上演练：迁移后标签总数不变、`course_tags` 行数不变、`tag_id` 不变；
- `[自动]` 拆分规则：第一个 `-` 前为分类名；无 `-` 归「未分类」；
- `[自动]` 迁移幂等：重复执行不重复建分类或标签。

### TL-6 三处界面

标签管理、新建/编辑课程、学习中心筛选 SHALL 按分类分组展示。

- `[手工]` 标签管理：分类分组、每组可加标签、显示引用数、可改名/删除；
- `[手工]` 新建/编辑课程：按分类分组多选，已选标签可单个移除；
- `[手工]` 学习中心：每个分类一个多选筛选，选中项以胶囊显示，可单个移除或清空。
