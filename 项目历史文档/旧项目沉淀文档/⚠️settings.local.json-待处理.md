# ⚠️ settings.local.json 含明文密码，使用前必须处理

`settings.local.json` 是从老项目 `.claude/settings.local.json` 原样复制过来的，**命令白名单里含有 MySQL 明文密码**（`MYSQL_ROOT_PASSWORD`、`MYSQL_PASSWORD` 等真实值）。

## 已确认的事实（非假设）

- 这份文件在老项目中**已被 git 追踪**，且**已实际推送**到 GitHub 和 Codeup 两个远端仓库（用 `git log` / `git ls-files` / `git branch -r --contains` 核实过）。
- 里面的密码应视为**已泄露**，不是"有泄露风险"。

## 使用前必须做的事

1. **不要把这份文件原样放进新项目的 git 仓库**，或者放之前先确认已加入 `.gitignore`。
2. **轮换老项目服务器上对应的 MySQL 密码**——删文件、改仓库都不能撤销已经被别人 clone 走的历史副本，只有改掉服务器上真实的密码才能让泄露的密码失效。
3. 新项目要用到的命令白名单/本地配置，建议参考这份文件的**结构**（哪些命令允许自动执行），但把其中的密码替换成从新项目 `.env` 读取的占位方式，不要手写真实值。

## 处理完成后

建议直接删除这份原始文件，只保留脱敏后的模板版本。
