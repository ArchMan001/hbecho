## 1. 背景

课程标签现在是**扁平一级**：

- `tags.name` 全局唯一，课程与标签多对多；
- 业务实际有四个维度（平台、板块、阶段、课程类型），只能写进标签名，例如 `平台-抖音`、`板块-直播`；
- 学习中心只能按**单个标签**筛选（`g-learning-min` 的 G-D14），无法表达「抖音 + 直播」这种跨维度组合；
- 标签管理是一张平表，看不出哪些标签属于同一维度。

结果：标签越多越难找，筛选只能一次一个，维度信息靠命名约定维持。

## 2. 需求

| # | 需求 | 说明 |
|---:|---|---|
| 1 | 两级标签 | 一级是标签分类（平台、板块、阶段、课程类型…），二级是标签值（抖音、直播…） |
| 2 | 一级分类可新增 | 超管可新建分类、改名；分类下有标签时不能删除，只能删空分类 |
| 3 | 同一分类下可多选 | 一门课可同时选「抖音 + 小红书」「短视频 + 直播」 |
| 4 | 每门课至少一个标签 | 沿用原 G-D21 |
| 5 | 筛选同类 OR、跨类 AND | 选「平台=抖音」+「板块=直播」→ 同时满足两类；同分类选多个 → 命中任一 |
| 6 | 旧标签迁移 | `平台-抖音` → 分类「平台」+ 标签「抖音」；无前缀归「未分类」；保留 `tag_id` 与课程引用 |
| 7 | 不改可见性 | 标签仍不参与品牌 / 人员级别过滤；不发新 Capability |

## 3. 三个页面的改动

### 3.1 标签管理（`/learning/tags`）

**改动前**：一张平表，所有标签混在一起；新增一个标签要忽略维度。

**改动后**：

- 按分类分组，每组一张卡片：分类名、标签数、分类内的标签表；
- 每组有自己的「在 XX 下新建标签」输入框；
- 分类级操作：新建分类、改名分类、删除空分类；
- 标签级操作：改名、删除；被课程引用的标签显示引用数且不能删除；
- 同一分类内标签名唯一，不同分类可以同名。

### 3.2 新建 / 编辑课程（`/learning/manage/new`、`/learning/manage/[id]`）

**改动前**：标签是一排平铺胶囊，没有维度；「筛选时单选」的提示与实际多选不一致。

**改动后**：

- 标签按分类分组，每组一行胶囊；
- 同一分类下可多选；
- 已选标签可逐个移除；
- 整门课至少选 1 个才能保存；
- 不要求每个分类都有值。

### 3.3 学习中心筛选（`/learning`）

**改动前**：一个「标签」下拉，只能选一个值。

**改动后**：

- 每个分类一行多选胶囊（`平台 / 板块 / 阶段 / 课程类型`…）；
- 同类多选取「或」，不同类之间取「且」；
- 已选项显示为胶囊，可单个移除或清空；
- 与标题搜索、「只看在学」、分页叠加；
- URL 使用重复的 `tag=<tagId>`，可分享、可后退。

## 4. 怎么改（实现要点）

### 4.1 数据模型

| 表 | 改动 |
|---|---|
| `tag_categories`（新） | `category_id` PK、`name` UNIQUE、`sort_order`、`created_at` |
| `tags` | 新增 `category_id NOT NULL` FK；唯一键从 `name` 改为 `(category_id, name)` |
| `course_tags` | 不变，仍为课程与标签的多对多 |

### 4.2 迁移 `0013`

1. 建 `tag_categories`，种子分类：平台 / 板块 / 阶段 / 课程类型 + 未分类；
2. `tags` 加可空 `category_id`，按标签名的**第一个** `-` 拆分并回填；
3. 无 `-` 的标签归入「未分类」；
4. 保留 `tag_id`，`course_tags` 不动；
5. 收紧 `category_id NOT NULL`、加外键、删除旧唯一键、加分类内唯一键。

迁移在库副本上先演练；拆分后同分类重名会让迁移失败，需人工处理，不静默合并。

### 4.3 Module 与页面

- `learning/tags.ts`：分类 CRUD、标签带分类、分类审计事件；
- `learning/read.ts`：多 `tag` 参数，按分类生成 `EXISTS`（同类 OR、跨类 AND），删除旧的 `multiple_tags` 限制；
- `learning/course-common.ts` / `manage.ts`：仍要求至少 1 个、最多 20 个、标签必须存在；
- 三处页面按第 3 节改；
- 不新增 Capability，沿用 `learning.read`、`learning.manage`、`learning.tag.manage`。
