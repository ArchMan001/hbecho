## 1. 怎么用

1. 写任何带页面的 spec 之前，先读本文件，再读该 spec 所属域的 PRD；
2. 该 spec 的 design.md 增加「界面」一节，按 §8 的模板写（页面清单、流程、线框、状态矩阵、字段可见性）；
3. **界面设计确认闸门**：界面一节与线框 / 原型必须交给刘学奎看并**明确确认**。规则最复杂的页面（判定计划三页向导、点检表等）先做可点击原型，请业务按真实任务走一遍，再请刘学奎确认；
4. **确认之前，该 spec 不得写页面相关的 tasks.md 条目，也不得写页面代码**。确认记录写在界面一节末尾的「N.6 界面设计确认」（确认人、日期、确认的页面范围、原型链接）。AI 不得把「用户没有反对」当作确认；界面改动超出已确认范围时需要重新确认；
5. 实现时逐条对照 §9 验收清单；不满足的项要么改，要么在 PR 里写明为什么例外；
6. 某个 spec 需要偏离本文件时，先改本文件（写明决策人、日期、推翻了什么），不在页面里各自发明。

> 这条闸门目前**只靠流程守**：没有脚本检查。`structure` steering 与 `CLAUDE.md` 已写入同一条规则；各 spec 的「页面任务」一节写明了进入条件。

## 2. 角色与导航

四类角色（B 域 PRD 是唯一定义源）。一级导航按角色显示；没有 Capability 的入口**不显示**，而不是显示后点击报错。

| 一级导航 | `platform_admin` | `hq_manager` | `branch_manager` | `store_staff` |
|---|---|---|---|---|
| 活动计划 | ✅ | ✅（授权品牌） | ✅（参加 / 名单） | — |
| 判定计划 | ✅ | ✅ | 只读 | — |
| 报表与看板 | ✅ | ✅ | ✅（本分公司） | 我的考核（本人一行） |
| 账号与监控 | ✅ | ✅ | ✅（本分公司） | — |
| 主数据 | ✅ | ✅（导入与纠错） | — | — |
| 学习 | ✅ | ✅ | ✅ | ✅ |
| 下载中心 | ✅ | ✅ | ✅ | — |
| 用户与权限 | ✅ | ✅（下级） | ✅（下级） | — |
| 系统 | ✅（审计、配置、外部账号、AI 调用与成本） | — | — | — |

**导航形态**

- **管理端（桌面）**：左侧浅色侧栏（白底、分组、选中项用品牌渐变）+ 顶栏（面包屑、账号菜单）。一个角色最多 9 个一级入口，顶部导航放不下；
- **门店端（`store_staff`，手机）**：底部 Tab，只有「我的考核」「学习」两项；没有管理类入口；
- **账号菜单**：修改密码、退出登录；其余入口不放在账号菜单里。

**三条必须记住的**

1. **菜单隐藏 ≠ 无权限**：每个页面、每个接口自己做 Capability 与 DataScope 校验；菜单只是入口。
2. **数据范围 = Capability × DataScope**（B 域）：品牌集合与组织范围求交（ADR-0010）。导航里所有入口看到的数据、计数、筛选项都必须按它收窄。
3. **手机端不提供管理类入口**：只有门店端面向手机优化。

## 4. 页面骨架

| 类型 | 结构 | 用于 |
|---|---|---|
| 列表页 | 标题与计数 + 主操作按钮 → 筛选栏 → 表格 → 分页；右上角「导出」（有权限才显示） | 计划、账号、用户、批次、课程 |
| 详情页 | 面包屑 → 标题与状态 → 关键数字（只计数，不做比率） → 标签页 | 活动计划、判定计划、批次 |
| 导入流程 | 下载模板 → 上传 → 预检报告（分类计数 + 可筛选明细） → 确认写入 → 批次详情 | F5 两条路径、用户批量导入 |
| 向导 | 顶部步骤条；只能按顺序前进、每次回退一步；回退前弹窗写明会删除什么 | 判定计划 |
| 报表页 | 筛选（计划 / 品牌 / 板块）→ 表格（多级表头、冻结首列）→ 页脚口径说明与数据截止时间 | 点检表、专员明细、命中内容 |
| 看板 | 标题与数据截止 → KPI 行 → 趋势（折线）→ 构成（环形 / 柱状）→ 分布条 | 计划看板 |
| 登录 | 整屏品牌渐变 + 白色大卡（左侧主张，右侧表单） | 登录、激活、忘记密码 |
| 门店端 | 单列、大字号、底部 Tab；一屏一件事 | 我的考核、学习中心 |

**异步动作**：确认写入、执行判定、导出、手工补抓提交后立即返回，页面显示「已提交」并给出去处（批次详情 / 执行记录 / 下载中心），不让用户停在转圈页面。

### 4.1 筛选与表格交互

- **筛选放在表格上方的一行**，不占左栏；常用顺序：计划 → 品牌 → 板块 → 分公司 → 状态。审计日志也按这一条执行（事件 / 时间两个下拉 + 已选说明），不设常驻左栏（2026-11-10）；
- **品牌单独一行**（有多个授权品牌时）：`全部品牌` + 已授权品牌；未授权品牌显示为锁定态，**不显示计数**；
- **已选条件**：每个条件一个胶囊，可单个移除，另有「清空」；
- **URL 即状态**：筛选、排序、分页、当前标签页都进 URL，可分享、可后退；
- **计数口径**：每个选项的数字 = 在其余已选条件基础上叠加该项的命中数；**分页总数与表格用同一条谓词**；
- **无权限**：不显示任何计数（显示真实数量等于泄露别的范围有多少条）；
- **表格**：
  - 表头不重复；报表多级表头并冻结首列与表头；
  - 数字右对齐，使用 `font-mono` + `tabular-nums`；
  - 默认每页 20，可选 50 / 100；列表一律分页，大范围导出走异步（E6）；
  - 综合状态列按优先级取第一条命中的状态（A §11.6），旁边可点开看三个维度；
  - 行可展开或点击下钻，下钻路径写在 spec 的「界面」一节。

## 5. 通用状态

每个页面都要设计下列状态，spec 的状态矩阵逐项填写：

| 状态 | 显示 | 注意 |
|---|---|---|
| 加载中 | 骨架屏，保留列表结构 | 不用全屏遮罩 |
| 空：确实没有数据 | 说明 + 下一步动作（如「去导入名单」） | 与「无权限」分开 |
| 无权限 | 「无权访问」页，说明找谁开通 | 直接访问 URL 也显示这个，不显示空列表、不显示计数 |
| 错误 | 一句人话 + 稳定错误码 + 重试 | 不显示堆栈 |
| 部分成功 | 成功数与失败数同时显示，失败可下载回流文件 | 导入、批量操作 |
| 处理中（异步） | 进度或「排队中 / 执行中」，可离开页面 | |
| 数据过期 | 页脚显示数据截止时间，`stale` 时加「当前显示上一版」 | E 域投影 |

**判定结果的三态**（D §1.4）统一用同一组颜色与文案，且**必须有文字**，不能只靠颜色：

| 状态 | 颜色 | 说明 |
|---|---|---|
| 成功 | 绿 | — |
| 不达标 | 红 | — |
| 未获取成功 | 灰 | **必须附原因**（同步失败 / 数据有缺口 / 平台不支持 / 媒资未归档 …） |

**数值的四种显示**：真实 0 显示 `0`；无数据或分母为 0 显示 `—`；没有参与显示「未参与」；部分覆盖显示数字加覆盖标记。不得用 0 代替 `—`（CONTEXT 不变量）。

**同步与校验状态**（A 域）：批次状态、身份校验的「一致 / 无法判定 / 不一致」三态分别展示，**无法判定不并入一致**（`a-full-sync` FS-15.7）。

## 6. 视觉、组件、文案与格式

### 6.1 色板（唯一来源：`src/app/globals.css` 的 CSS 变量，落地时建立；对照 hbdam ui-lab 的同名 token）

| 用途 | 值 | 说明 |
|---|---|---|
| 画布 | `#F2F5F9` | 页面底色，**纯色**，不用渐变 / 柔光 |
| 卡片 | `#FFFFFF` | 所有内容容器 |
| 主文字 | `#17202A` | 正文与标题 |
| 次文字 | `#566070` | 说明、表单标签 |
| 辅助文字 | `#66707F` | 计数、时间、页脚；对画布约 4.6:1、对白卡约 5.0:1（按 WCAG 公式估算，落地时用工具复核） |
| 分隔线 | `#E4E9F0` / `#EFF3F7` | 外框 / 内部分隔 |
| 品牌渐变（默认） | `linear-gradient(135deg,#0FA3A8 0%,#2B7DB6 100%)` | 登录页背景、主按钮、侧栏选中项、头像、进度条、图表主色；**可承载白字**。按 hbdam 的已知例外：白字对起点约 3.08:1、终点约 4.46:1（2026-11-08 刘学奎确认） |
| 选中芯片 / 筛选选中 | 底 `#E9F5F6`、文字 `#0A6F74`、描边 `rgba(15,163,168,.45)` | 筛选与标签的选中态（2026-11-10）；白字对比不再依赖渐变，文字对浅底约 5.3:1 |
| 按钮渐变（可选高对比） | `linear-gradient(135deg,#0B7F85 0%,#2873AB 100%)` | 只在需要 ≥ 4.5:1 的小字 / 密集界面使用；白字约 4.8:1 起。不是默认按钮色 |
| 青绿 / 蓝 / 深青 | `#0FA3A8` / `#2B7DB6` / `#155E8C` | 状态、图表主色 / 次色 / 深色链接 |
| 警示 | 文字 `#B45309` / 底 `#FFF4E5` | 待更新、限制说明、部分覆盖 |
| 成功（状态色） | 文字 `#1A7F54` / 图形 `#22A06B` / 底 `#E8F6EF` | 判定「成功」、批次成功 |
| 危险 / 不达标（状态色） | 文字 `#B42318` / 图形 `#E5484D` / 底 `#FDECEC` | 判定「不达标」、失败、删除、未读点 |
| 未获取成功（状态色） | 文字 `#566070` / 底 `#EEF1F5` | 灰，不是错误色 |

**渐变只做「按钮与反馈」**：主按钮、侧栏选中项、登录页背景默认用**品牌渐变**；进度条、头像、图表主色同。不铺大面积背景（登录页除外）。**凡承载文字的渐变默认用品牌渐变**，按 hbdam 的已知对比度例外接受；小字 / 密集界面可改用**按钮渐变**（可选高对比变体），落地时用工具复核对比度。选择类控件（筛选芯片、标签页切换）用浅底 + 品牌深色文字，不用渐变（2026-11-10）。

### 6.2 字号与字重

| 层级 | 字号 / 字重 | 用在哪 |
|---|---|---|
| 页面大标题 | 30–34 / 600，字距 -0.02em | 看板标题；登录主张见下方例外 |
| 页面标题 | 26 / 600，字距 -0.022em | 各页 h1（2026-11-10） |
| 概要层 | 17 / 600 | 概要带的说明行（2026-11-10） |
| 区块标题 | 15.5 / 600 | 卡片区标题、面板标题、弹窗标题 |
| 正文 | 13.5 / 400 | 段落、表格 |
| 次要正文 | 12.5 / 400 | 副信息、表单、页头说明 |
| 辅助 | 11.5 / 400–500 | 标签、计数、说明 |
| 极小 | 11 / 400–500 | 仅徽标、角标，**不用于正文** |

数字排版（2026-11-10）：计数与日期用无衬线 + `font-variant-numeric: tabular-nums lining-nums`；**等宽字体只用于内部 ID、稳定错误码、时间轴时间**。中文正文不用衬线。**门店端正文不小于 14px。**

登录页主张是例外：按 2026-11-08「登录页按 hbdam 当前设计」的决策，主张标题可用 clamp(40–58px)；登录页用纯白文字靠字重与字号分层，不用透明度。

### 6.3 间距、圆角、层次、图标

- 间距用 4 的倍数：卡片内 12 / 16，卡片之间 12 / 16，区块之间 24 / 32；
- 圆角：控件 8–10，卡片 12，登录大卡 20，芯片 8（胶囊形仍可用 999）；
- 层次靠「画布 → 白卡 → 悬浮面板」三层 + 1px 边线；**卡片常驻不带阴影**，阴影只用于弹窗、浮层与 hover 浮起；
- 图标统一 lucide，14–16px，`strokeWidth` 1.7–2；不用 emoji 当图标。

### 6.4 组件

shadcn/ui 是组件来源（ADR-0005）：表格、表单、弹窗、步骤条、标签页、Toast 都用 shadcn 现成组件；视觉通过 CSS 变量与 `cva` 变体实现，**不改 shadcn 组件源码里的其他变体**；需要新增第三方组件库时，按 `no-reinventing-wheels` 先登记。

| 组件 | 规则 |
|---|---|
| 主按钮 | 品牌渐变底白字，高 36–44；一屏只有一个主按钮；小字 / 密集界面可用按钮渐变（可选高对比） |
| 次按钮 | 白底 1px 边线，文字用次色 |
| 危险按钮 | 确认弹窗里用实心红；**页面头部用白底 + 1px 浅红边 + 红字**，hover 才实心，避免与主按钮抢层级（2026-11-10） |
| 返回链接 | 34px 白底描边按钮：箭头 16px、文字 12.5px、圆角 9；hover 边框变深、箭头左移 2px（2026-11-10） |
| 图标按钮 | 36–40 方形，必须有 `aria-label` |
| 输入框 | 高 40–44，聚焦 `ring` 用青绿 14% 透明度；标签始终可见 |
| 下拉 | 触发按钮显示当前计数；面板 2 列以内，长列表内部滚动 |
| 芯片 / 徽标 | 状态必须有文字，不能只靠颜色；筛选选中态用浅底 + 品牌深色文字，不用渐变 |
| 角色标识 | 中性描边标签（白底、1px 边线、次文字色）；绿色 / 琥珀 / 灰色只表示状态（2026-11-10） |
| 卡片 | 白底 12px 圆角，1px 边线，不带常驻阴影；选中用 1px 青绿描边 |
| 表格 | 见 §4.1；行 hover 高亮 |
| 分页 | 上一页 / 下一页 + 页码；禁用态用浅底深灰，不用 `opacity` 掉到不可读 |
| 步骤条 | 向导专用，当前步高亮，已完成步可回退一步 |
| 图表 | 折线用于趋势、柱状用于比较、环形用于构成；没有图表库时手写 SVG，并给数据表或文字摘要 |
| 上传 | 拖放 + 选择文件；显示文件数与总体积；超限在提交前拦住 |
| 媒资缩略图 | 读取 A 域**正式媒资**的标准化衍生图（JPEG q80、540 宽），保持原比例 `object-cover` 裁切、列表 `loading="lazy"`；缺失用中性底 + 图标占位，不生成假图；**绝不使用供应商临时 URL**；媒资标注「本轮未归档成功 / 沿用旧图」时要显示该标记 |

### 6.5 确认弹窗

删除、回退、全局关闭监控、停用用户、取消批次、重试失败任务必须弹窗，写明影响范围（例如「下面有 3 个判定计划、共 1,284 条结果将被删除」），按钮文字写动作本身（「删除计划」），不用「确定」。影响多个对象的操作先给预览再确认（对应命令行的默认预览 + `--apply`）。

| CONTEXT / 代码 | 界面 |
|---|---|

内部字段名、表名、`reason_code` 不直接出现在界面；界面显示人话 + 稳定错误码。

### 6.7 格式

- 时间按北京时间显示，精确到分钟；导出文件同样；
- 内部 ID 不在界面出现；需要时以字符串显示，不做数字运算；
- 数字千分位；比率保留一位小数，例如 `62.5%`；
- 手机号明文显示（D-42），随行可见；
- 文件体积用 B / KB / MB / GB，一位小数。

## 7. 适配与可访问性

- **管理端**（除 `store_staff` 外的全部页面）：桌面浏览器，最小宽度 1280px；手机能打开但不专门优化；
- **门店端**（我的考核、学习中心）：移动优先，兼容微信内置浏览器；微信内不能下载时提示「在浏览器打开」（G-D35）；
- **对比度**：正文与辅助文字 ≥ 4.5:1；状态色文字用 §6.1 的「文字」档，图形档只用于圆点、描边、图表；
- **只用颜色区分的状态必须同时有文字**；键盘可以完成主要操作；所有表单控件有可见标签；
- **焦点**：所有可交互元素有可见 `focus-visible` 圈（青绿）；Tab 顺序与视觉一致；
- **目标尺寸**：桌面 ≥ 36px，手机 ≥ 44px；
- **动效**：150–300ms；尊重 `prefers-reduced-motion`；
- **图片**：有意义的缩略图写 `alt`；纯装饰 `alt=""`。
