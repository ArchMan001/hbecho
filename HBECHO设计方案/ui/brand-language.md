## 0. 方向校准（2026-11-11，刘学奎）

两次校准的边界很清楚：

- 初稿写成"山谷会记得每一次发声"——太抽象、太装；本产品是给总部、分公司、经销商共用的内部业务系统，不是品牌宣传片。
- 第二版写成"谁发了，谁没发，发得怎么样"——太像后台标语，土。

最终口径：**高级 + 文艺 + 行业感**。

1. **H1 要有节奏和气势**，可以文艺、可以用行业词，但不许空洞。"让终端发声，让声量可见"是这条线，两侧边界分别是上文的两个反例。
2. **说明文案可以用互联网黑话**（内容资产、矩阵、链路、闭环、归集、度量、种草、声量），一段最多两个，且必须对得上系统里真实存在的功能。
3. **高级来自结构**：对仗、短句、精确数字、留白；不来自形容词堆砌。
4. **登录页事实区用业务数字**：参与门店数、发布视频数、用户互动数。

## 1. 名字

| 层 | 内容 | 状态 | 用在哪里 |
|---|---|---|---|
| 正式名 | **Echo** | ✅ 2026-11-11 确认 | 登录页、页面标题、对外物料 |
| 中文副标题 | **新媒体营销智能体** | ✅ 2026-11-11 确认 | 品牌区第二行、侧栏、文档标题 |
| 仓库代号 | hbecho | 不改 | 仓库、包名、环境变量、历史文档 |
| 模块名 | 先声 | ⏳ 待定 | 活动计划 / 节点任务 |
| 榜单名 | 回声榜 | ⏳ 待定 | 考核与奖励 |

原则：**平台名承担独特性，副标题承担"这是什么"**。

### 1.1 为什么不需要把"先声"和"回响"合并成一个词

两者不是并列的两件事，是同一条时间轴的两端：先有声，后有回响。Echo 本身就是时序词。再造融合词只会得到既不准确也不上口的第三词。

### 1.2 中文副标题（已定）

**`Echo · 新媒体营销智能体`**。

不用"经销商"作前缀：总部、分公司、经销商共用同一入口，副标题不能只对其中一极说话。
不用"矩阵"：行业黑话，且在 §5 的克制清单内。

### 1.3 品牌故事（内部叙事，不上界面）

Echo 是希腊神话中的宁芙：被惩罚只能重复别人的话，爱上 Narcissus 被拒，形体消散，只剩声音在山谷回荡。**直接讲"Echo 是回声女神"是用错了典故。** 正确的用法是反转：神话里的 Echo 只能重复，我们做的是让经销商自己的声音被听见并传回来。

这一段只用于内部对齐、发布会和招聘，**不写进任何界面文案**。

## 2. 登录页 H1（已定）

2026-11-11 刘学奎选定 **B 版组合**：三段排比做主标题，意象句做副题。

```
内容有标准，
发布有回响，
增长有数据。

让每一家门店，都成为品牌的发声场。
```

版式层次：

| 元素 | 字号 / 处理 |
|---|---|
| H1（三行排比） | 58px，全白，行距收紧 |
| 副题（一行） | 24px，白 80% |
| 事实区 | 26px 数字 + 11.5px 灰标签，竖线分隔 |
| 定位句 | 12px，白 55%，事实区下方，留 32px |

右侧登录卡下方保留一行脚注：`把分散在账号里的内容，变成可度量、可复用的品牌资产。`
左边讲范围，右边讲价值，不重复。

其余候选保留作对照，不再使用：

| # | H1 |
|---|---|
| A | 让终端发声，让声量可见。 |
| C | 每一次发布，都在放大品牌声量。 |

## 3. 声学词库

**只在模块名与导航使用；按钮、表格、表单、错误提示一律说人话。一个界面最多两个隐喻词。**

| 概念 | 词 | 是否进界面 |
|---|---|---|
| 活动节点 | 先声 | ⏳ 模块名 |
| 数据回流 / 考核依据 | 回声 | ⏳ 榜单名 |
| 学习内容 | 声场 | ⏸ 储备 |
| 账号 / 门店 | 声源 | ⏸ 储备 |
| 多品牌并列 | 和声 | ⏸ 储备 |
| 该发未发 | 静默 | ⏸ 储备 |
| 异常 / 刷量 | 杂音 | ❌ 仅内部 |

## 4. 语气

1. **说人话，不说系统话。** ✗ 您有 3 项待处理事项 ／ ✓ 这周还有 3 条要发
2. **具体，不宏大。** ✗ 上周 12 家门店没发，3 家发了但没带话题 ／ ✓（保留，不加形容词）
3. **平静，不嚷嚷。** 不用感叹号，不承诺做不到的事。

| 场景 | 调性 | 示例 |
|---|---|---|
| 登录 / 引导 | 有分量、有节奏 | 让终端发声，让声量可见。 |
| 任务与提醒 | 明确、简短 | 本周任务：3 条短视频，周五 18:00 截止。 |
| 考核与奖励 | 公正、具体 | 本月达标 8/10，声量进入前 20%。 |
| 错误与失败 | 交代原因与下一步 | 视频上传中断，已保留草稿，可重新上传。 |
| 空状态 | 一句事实 + 一个动作 | 还没有内容。第一条发出去后，数据会出现在这里。 |

## 5. 用词边界

**允许、但要克制**（一段文案最多两个）：内容资产、矩阵、链路、闭环、归集、度量、沉淀、种草、声量、转化。

**仍然禁用**：

- 空话：赋能、抓手、生态、打通、全方位、多维度、助力、极致、颠覆
- 假大空承诺：一键、轻松、重磅、全新升级
- 内部术语泄漏：Capability、DataScope、ODS、采集任务、实体、主档

理由：行业词用来**对齐语境**，不是用来掩盖没话说。一段文案里出现两个以上，说明内容不够。
