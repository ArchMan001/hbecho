## 覆盖的页面

| 页面 | 角色 | 说明 |
|---|---|---|
| 学习中心（课程列表） | 四类角色 | 标题搜索、单标签筛选、只看在学；卡片显示在学与续播位置 |
| 课程详情 · 视频 | 四类角色 | 播放器与续播、进度栏；转码中显示「暂不可播放」 |
| 课程详情 · 资料 | 四类角色 | PDF / 图片预览；下载原件（记审计）；微信内改为复制链接提示 |
| 课程管理 | 超管、总部 | 含已下架、已归档、转码中的课程；新建、编辑、下架 / 上架 |
| 新建 / 编辑课程 | 超管、总部 | 类型、标题、简介、品牌范围、适用人员级别、标签、封面与文件；保存即发布 |
| 学习汇总 | 超管、总部 | 四项累计指标；合计与单品牌切换；口径说明 |
| 标签管理 | 超管 | 新建、改名、删除；删除被引用标签返回 409 与引用数 |

其余一级导航（活动计划、判定计划、报表、账号与监控、主数据、用户与权限、系统、门店考核）在原型里只有外壳，标注「不在本次学习平台原型范围」。

## 怎么打开

在仓库根目录运行：

```bash
python3 -m http.server 4175 --directory ui-lab/g-learning-min
```

然后打开 <http://localhost:4175/>。A/B 基线原型在 `4174`（[`../hbecho-ui-v2/`](../hbecho-ui-v2/README.md)），可以同时开。

## 建议走查顺序

1. 超管：学习中心 → 打开视频课（从 8:32 继续）→ 打开资料课（预览 / 下载）→ 搜索「水机」→ 只看在学；
2. 超管：课程管理 → 新建课程（不选标签直接保存看校验；再选标签保存）→ 下架 / 上架；
3. 超管：学习汇总 → 在合计与单品牌之间切换 → 读四条口径；
4. 超管：标签管理 → 新建标签 → 删除被引用的标签（提示引用数）→ 改名；
5. 切到总部：确认只能看到日立 / 海信；新建课程时约克 VRF 带锁不可选；课程管理不含约克课程；
6. 切到分公司 / 门店：只剩「学习中心」；课程列表按品牌与人员级别收窄；直接访问海信课程 → 无权访问；
7. 在「原型控制」里切空 / 加载 / 无权限 / 错误 / 处理中 / 已过期，核对状态矩阵；
8. 手机视口（390×844）检查课程列表、筛选折叠、课程详情与底部 Tab。

## 已知边界

- 视频播放、上传、下载、进度上报都是原型交互，不产生真实请求；没有接 VOD 与 OSS。
- 看不到「已完成」：按 G-D02，1.0 只记录位置与进度，不定义完成状态。
- 汇总的累计数字是演示造数；课程数与演示课程集一致（已发布且可播放），单品牌按品牌范围统计。
- 课程管理含 10 门演示课程，覆盖已发布、已下架、已归档、转码中与转码失败；学员侧只出现已发布且可播放的 6 门。
- 管理端按桌面优先，手机端保留基础响应式与底部 Tab。
