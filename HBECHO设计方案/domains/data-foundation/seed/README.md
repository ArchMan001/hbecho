# 主数据种子

本目录存放**不随业务变化**的权威对照数据，作为主数据导入的固定输入。改动这里等同于改数据，需要单独说明原因。

| 文件 | 内容 | 来源 | 维护 |
|---|---|---|---|
| `分公司-大区对照.csv` | 42 个分公司 → 4 个大区（北区 1110 / 华东 1130 / 华南 1150 / 西区 1140） | `门店信息报表_2026-10-28 14_35.xlsx` 中「大区 / 大区CRM部门编码 / 所属分公司 / 分公司编码」四列提取 | 组织调整时更新 |

**字段**：`大区编码,大区,分公司编码,分公司`；UTF-8 带 BOM，可直接用 Excel 打开。

**为什么单独一张表**：权威门店导出里没有大区，而报表上卷与数据范围都需要它。42 行、一个分公司只对应一个大区，放在这里比在 8,000 行数据里重复一列更干净。

**校验**：提取时已确认 42 个分公司各只对应一个大区、编码无冲突、与门店主档的分公司名称 42/42 一致。
