## 怎么打开

在仓库根目录运行：

```bash
python3 -m http.server 4100 --directory ui-lab   # 本机已有 4100 常驻时不用再起
```

然后打开 <http://localhost:4100/hbecho-ui/>。页面使用 ES modules，必须通过 HTTP 打开，不能直接双击 `index.html`。

## 原型控制

右下角「原型控制」不是产品界面，用于评审：

- **当前角色**：切换平台超管 / 总部人员 / 分公司人员 / 门店专员，检查导航、列表范围、按钮权限与「未找到」语义；
- **页面状态**：正常 / 空 / 加载中 / 无权限 / 错误 / 处理中 / 已过期；
- **桌面优先**：本轮以 1280px 以上为主；窄屏保留基础可用，不作为评审重点。
- **快捷跳转**：登录、计划详情、名单导入、批次详情、账号与监控、用户列表、用户导入、审计、门店端。

## 建议走查顺序

1. 登录 → 活动计划列表 → 计划详情 → 名单标签 → 上传名单 → 预检 → 确认 → 批次详情；
2. 账号与监控 → 选一个「疑似空账号」→ 看监控开关链 → 确认疑似空账号；
3. 用户与权限 → 用户详情 → 停用 / 恢复 / 强制下线；
4. 用户批量导入 → 预检（含越权行、手机号已存在）→ 确认 → 回流文件；
5. 审计日志；
6. 在「原型控制」里切到总部 / 分公司 / 门店，重复第 1–3 步，检查导航与范围；
7. 在「原型控制」里切空 / 无权限 / 错误 / 处理中 / 已过期，检查状态矩阵；
8. 手机视口（375px 左右）检查登录、计划列表、底部 Tab 与筛选面板。

## 评审后

- 本原型通过后，在 A / B 两个 spec 的 design §15.6「界面设计确认」填写确认人、日期、页面范围、原型链接；
- 确认前不写页面任务、不写页面代码（`structure.md` 与 `ui-foundation.md` §1）；
- 页面实现时按 `ui-foundation.md` 的 token 在 `src/app/` 重新实现，**不复制本目录代码**。

## 已知边界

- 表格在窄屏是横向滚动，不是移动端卡片；管理端按桌面优先，门店端单独有底部 Tab。
- 文件上传、下载、开关写入、登录、导出都是原型交互，不产生真实请求。
- 用户导入的错误码、批次行结果、账号综合状态是评审样例，不是穷举。
- 未实现页面（判定计划、报表、主数据、学习、系统）只保留外壳与导航，明确标注「不在本次 A/B 原型范围」。
