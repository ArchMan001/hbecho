# ADR-0011 · 报表导出用 exceljs（仅写入）

- **状态**：accepted
- **日期**：2026-11-04
- **决策人**：刘学奎
- **关闭**：修订清单 R6-01「Excel 导出没有选型」
- **与 ADR-0005 的关系**：ADR-0005 否决 exceljs 的理由针对**导入**（解析不可信的外部 xlsx：原型污染、压缩炸弹）。本 ADR 只允许它**写**自己的数据，导入仍只用 CSV（D-08）。

## 背景

E 域 E6 要导出带合并表头、冻结行列、条件着色、嵌入封面图的多 sheet Excel（E §8.1、§8.3）；D 的判定结果也是三个 sheet 的 Excel，由 E6 生成（E-D04）。CSV 做不到这些格式。

旧系统 lxk-BigSpard 的主链路已经用 exceljs 4.4.0 在 Node 侧实现了这些能力：`web/src/routes/export.js` 里有冻结行（`views: [{ state: 'frozen', ySplit: 3 }]`）、`mergeCells` 多层表头、`addImage` 从 OSS 取图嵌入、多 sheet，最后 `wb.xlsx.write(res)` 写出。

exceljs 上游停在 4.4.0，2026 年仍有修复原型污染等问题的 PR 未合并。这些问题主要出现在读取路径。

## 决定

采用：exceljs 4.4.0（MIT）

用途：在 Node Worker 里生成报表与判定结果的 xlsx：合并单元格、冻结、样式、条件着色、嵌图、超链接、多 sheet。

不用它做什么：

- **不读取任何外部 xlsx**。代码里不得出现 `workbook.xlsx.read*` / `load`；导入只用 CSV。
- 不在 Web 请求进程里生成大文件；导出是异步任务，在 Worker 里跑（ADR-0005 进程形态）。**2026-11-19 订正（刘学奎，`e-metrics-lite` U1）**：本条针对**带图**的大工作簿。**无图、用流式写入器、有硬行数上限（视频明细 5 万 / 账号维度 5,000 起始值，实测后定稿）、进程内最多 2 个并发**的导出，允许在 Web 请求里同步流式生成，这是 `e-metrics-lite` 的导出路径；带图导出与超限仍走异步任务。实测单次 > 20 秒或峰值 RSS > 300 MB 时，`e-metrics-lite` 改走异步。
- 不负责范围过滤、口径与文件交付：数据由 E 的查询接口按 DataScope 流式提供，私有存储、签名下载与三次范围复查归 E6 / B。

## 风险控制

| 风险 | 控制 |
|---|---|
| 上游停滞、未修 CVE | 锁定 `4.4.0`（不加 `^`）；CI 依赖审计；只走写入 API，不触达读取路径 |
| 内存占用 | 旧系统用的是非流式写法，先在内存建完整工作簿。带图导出受 E §8.5 硬上限约束（行数、图片数、单图大小、文件大小、时长），超限降级为链接并返回 warning；导出 Worker 单独限内存 |
| 大表无图导出 | 是否改用 exceljs 流式写入器 `stream.xlsx.WorkbookWriter`，在 `e-metrics` spec 实测后定。流式写入器对嵌图的支持未核实，不预先假定可用。**2026-11-19 订正**：无图的大表由 `e-metrics-lite` 首个落地并实测（任务 T5，结果回填 `e-metrics-lite` design §7.1 / §12 与本行）；带图仍待 `e-metrics` 实测 |
| 单元格公式注入 | 以 `= + - @ \t \r` 开头的文本单元格加 `'` 前缀（与 F-D11 一致） |

## 备选与不选原因

| 候选 | 不选原因 |
|---|---|
| Python 侧 XlsxWriter | 只写不读，维护活跃；但要把数据与图片跨进程传给 Python 服务，并让 Python 服务多承担一类与图像识别无关的职责 |
| 1.0 只导 CSV、不嵌图 | E-D04 与 E §8.3 的格式要求做不到，业务体验降一档 |

## 后果

- 如果 exceljs 写路径出现未修的高危 CVE，再评估维护中的 fork 或 XlsxWriter；现在不为此提前引入第二套导出实现。
- `package.json` 里 exceljs 必须是精确版本；依赖审计放进 CI。

## 现在谁在守

- `e-metrics` spec 的导出测试（上限、降级为链接、公式前缀）；
- 代码审查：搜索 `xlsx.read` / `xlsx.load` 必须为零。
