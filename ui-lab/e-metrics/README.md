## 打开方式

在仓库根目录：

```bash
python3 -m http.server 4100 --directory ui-lab
```

打开 <http://localhost:4100/e-metrics/>；也可以从 ui-lab 总览页 <http://localhost:4100/> 进入。

## 走查任务

用一句话：**总部月底打开 618 活动的组织点检表，按分公司完成率排序，下钻未达标专员，看命中内容与证据，导出 Excel，再去下载中心取回。**

建议按这个顺序走：

1. **组织点检表**：当前是「家装」板块，含两个判定计划列组；点「完成率」表头切换排序；展开「华北 → 北京分公司 → 门店」；
2. 点某个分公司的完成率 → **专员明细**（筛选结果 / 组织 / 平台），点一行 → **命中内容**；
3. 在命中内容点「查看证据」→ 看圈定 / 内容层 / 评论层 / 账号层；证据已过期的行仍保留、入口不可点；
4. 右上角「导出 Excel」→ 选择对象 → 提交 → 点导航「下载中心」看任务状态（取消 / 重试 / 重新下载）；
5. 左侧「计划看板」：先看「全部判定计划」（不显示合并比率）→ 选一个判定计划 → 看分公司对比；
6. 左侧「指标字典」：查看内置 / 派生 / 自定义指标 → 新建自定义指标 → 保存并发布 / 归档 → 看影响面；
7. 左侧底部切换角色：**分公司人员**（本范围合计，同步成功率与未归属显示 `—`）→ **门店专员**（我的考核，单列、无导出、无证据入口）；
8. 底部「演示状态」切换加载 / 空 / 查询失败 / 无权访问 / 正在重算 / stale。

## 页面与路由

| 页面 | 路由 | 说明 |
|---|---|---|
| 组织点检表 | `#/reports?sector=home\|water` | 按板块分表；大区 / 分公司 / 门店；固定列 + 每个判定计划一组列；页脚口径 |
| 专员明细 | `#/staff?plan=…&result=…&org=…&platform=…` | 一人一行；计划总结果 + 三项层结果 + C1/C2/C3 + 基础指标 + 最后观测 |
| 命中内容 | `#/hits?plan=…&staff=…&org=…` | 内容级通过全部内容层的行；证据抽屉；同一作品在不同账号各一行 |
| 计划看板 | `#/board?plan=…` | 六张卡片：当前计划完成率、各计划、分公司对比、未获取分布、数据质量、最近执行 |
| 指标字典 | `#/metrics` | 内置 4 个、每个判定计划 4 个派生、受限自定义指标；新建 / 发布 / 归档 / 影响面 |
| 下载中心 | `#/exports` | 本人任务；状态、行数、大小、过期时间、重试 / 取消 / 重新下载 |

门店专员登录后 `#/reports` 渲染「我的考核」，只显示本人；没有看板、指标字典与下载中心入口。

## 状态覆盖

- 加载：骨架屏保留列表结构；
- 空：事件化空态（「这个活动还没有判定结果」「没有符合条件的专员」「没有通过全部内容层的内容」）；
- 无权限：整页「无权访问」，**不显示任何真实计数**；
- 错误：人话 + 稳定错误码 `REPORT_QUERY_FAILED` + 重试；
- 处理中：横幅「正在重算，当前显示上一版」，页面继续可读；
- 过期：`stale` 徽标 + 数据截止 + 「当前显示上一版」；
- 部分成功：点检表行标黄 + 「部分覆盖」；专员行标注原因；
- 四态：真实 0 显示 `0`、无数据 / 分母 0 显示 `—`、未参与显示「未参与」、部分覆盖显示数字 + 标记。

## 原型数据

全部为**程序合成的脱敏数据**，不连真实接口、不调用 A / B / D / OSS。数字保持自洽：

- 活动「618 家电焕新季」：10 家分公司、190 名专员（家装 186 人、水机 142 人，有交集）；
- 家装：主推 v3 · 186 / 121 / 14（完成率 65.1%），家装切片 v1 · 98 / 61 / 6（62.2%）；
- 水机：视频 v2 · 142 / 96 / 9（67.6%），直播切片 v2 · 142 / 88 / 12（62.0%），两个计划**同一人群**；
- 家装切片是两个板块中唯一的「同一人群」示例之外的四列组；水机两个计划共用分母；
- 每个分公司的「完成人数 + 不达标 + 未获取成功 = 考核人数」；大区按分公司分量求和，不平均百分比；
- 命中内容行集来自专人 C3 条数；同一作品在不同账号各一行；
- 石家庄在水机板块「已退出活动 / 未参与」；成都家装行「部分覆盖」；南京「已退出活动」；
- 下载中心预置成功 / 执行中 / 排队中 / 失败 / 含 warning / 已过期六种任务。
