## 1. 引言

### 1.1 为什么有这个 spec

四个品牌（日立、海信、约克 VRF、科龙）的经销商各自发布大量短视频与图文。现在没有一个地方让他们看到「别人做得好的作品」。本 spec 交付一个**公共的只读作品借鉴广场**：登录用户按品牌、平台、类型、活动计划、分公司、发布时间、点赞数筛选，用标题关键词搜索，浏览作品卡片，跳转到原平台观看，并预留「AI分析」入口。

「官媒阵地」（官方号作品广场）是同一个页面的第二个标签，**本次不做**；它依赖外部账号的内容采集，当前系统不采集外部账号的作品列表（database-design-v2 §8.3）。

### 1.2 权威顺序

1. [`CONTEXT.md`](../../../CONTEXT.md)：`Content`、`ExternalAccount`、`AccountAssignment` 词汇与不变量；
2. `database-design-v2.md` §8 / §10 / §11：只读，**本 spec 只新增一张表**（§5 的 `square_brand_policies`），不改既有表；
3. B PRD：Capability 注册表是唯一清单，新增 Capability 走 B 评审；
4. `ui-foundation.md`：导航、筛选、卡片、弹窗；
5. 本 spec：不得静默改写以上事实。

## 2. 范围边界

### 2.1 做什么

1. 页面 `/square`：经销商视频广场，所有有 `square.read` 的登录用户可进入（四个角色默认都有）。
2. 三行芯片筛选，**单选**：品牌（默认全部）、平台（默认全部）、类型（默认视频；选项：全部类型 / 视频 / 图文）。选项只列**已采集到内容**的品牌 / 平台。
3. 一行下拉与搜索，**单选**：参与活动计划（v1 置灰）、分公司、发布时间（全部 / 7 / 30 / 90 / 180 天内）、点赞数（全部 / 51–100 / 101–300 / 301–500 / 500 以上）；标题搜索框 + 「搜索」「重置」按钮。
4. 恒定条件：只展示点赞为有效值且**大于 50**的作品；只展示 `active` 内容。
5. 卡片网格，按点赞数从高到低，服务端分页（每页 20）。卡片只露出：**标题、点赞、评论、品牌标签、账号名**，加封面、平台与类型角标。
6. 卡片悬浮出现「观看」「AI分析」：「观看」在新标签页打开作品原链接；「AI分析」v1 弹「功能正在开发中」。触屏与窄屏不依赖悬浮，按钮常驻卡片底部。
7. 观看品牌范围可控：每个**观看者品牌**可被设置为「看全部品牌」（默认）或「只看本品牌」（§5）。

### 2.2 明确不做

| 不做 | 原因 / 归属 |
|---|---|
| 官媒阵地 | 刘学奎 2026-11-18：暂时先不做；依赖外部账号作品采集 |

| AI 分析、AI 仿写的真实能力与对话 | 另立 spec；H5 授权范围（授权品牌）与跨品牌广场的冲突届时再定 |

| 品牌范围策略的管理页面 | v1 只提供模块函数与 CLI（§5、design §5.4）；页面另议 |
| 作品详情页、评论展示、导出、排序切换、多选筛选 | 不在本切片 |
| 专员姓名、门店名、门店编码、账号内部 ID | 卡片与读口都不返回（§4） |

## 4. 需求与验收标准

### R1 · 入口与权限

1. 页面与读口 SHALL 要求 Capability `square.read`；没有则显示无权限态，不出现任何计数或内容。
2. `square.read` SHALL 授予全部四个角色。四个角色看到的**字段完全相同**，不因角色隐藏卡片字段。
3. 观看者没有任何品牌范围（空范围）时 SHALL 显示无权限态，不得回退成「看全部」。

### R2 · 观看品牌范围

1. 每个观看者品牌 SHALL 有一个策略值 `all`（看全部品牌）或 `own`（只看本品牌）；**没有策略行等同 `all`**。
2. `platform_admin`（品牌范围 all）SHALL 始终看全部品牌，不受策略影响。
3. 观看者有多个授权品牌时，只要其中**任一品牌**策略不是 `own`，即可看全部；全部授权品牌都是 `own` 时，只看这些品牌自己的内容。
4. 品牌筛选的选项 SHALL 只列观看者可见的品牌；不可见品牌既不出选项也不出计数。
5. 策略变更 SHALL 记审计事件，且只有超管可以变更。

### R3 · 展示的作品集合

1. 只含 `contents.status='active'`、有 finalized current 快照、`content_kind ∈ {video, image, text}` 的内容；`unknown` 不展示。
2. 只含账号**当前有归属**的内容：归属类型为专员（`watch_type='staff'`）且名额未释放（`slot_released_at IS NULL`）；外部账号（竞品、官方号）不出现。**不看 `monitoring_enabled`**：手动停采但名额未释放的账号，其历史作品仍展示（v1 简化，见 U3）。
3. 点赞 SHALL 同时满足 `like_state='value'` 与 `like_value > 50`。点赞缺失、显式 null、非法或不支持的内容一律不出现在广场，也不得被当作 0 处理。
4. 「视频」= `video`；「图文」= `image` 与 `text`（与 D 域口径一致）。

### R4 · 筛选与搜索

1. 品牌、平台、类型、分公司、发布时间、点赞数：各取一个值；非法取值 SHALL 报「筛选条件无效」，**不得静默当成全部**。
2. 发布时间「N 天内」按 UTC 当前时刻回推 N 天；发布时间缺失的内容在选了时间范围时不出现。
3. 点赞区间边界：51–100、101–300、301–500 含两端；「500 以上」= 大于 500（≥501）。
4. 标题搜索为包含匹配，大小写不敏感，`%` `_` `\` 按字面处理；关键词最长 100 字，超出报错，不截断。
5. 「重置」把品牌、平台、类型、分公司、发布时间、点赞数、搜索词全部恢复为默认并回到第 1 页。
6. 平台与品牌选项 SHALL 数据驱动：只列当前可见集合里真实存在内容的值。未验证的平台（如视频号）不出现。

### R5 · 卡片与跳转

1. 卡片 SHALL 显示：封面（正式媒资标准化衍生图，缺失或签名失败用占位）、类型角标、平台角标、标题（最多两行）、点赞、评论、品牌标签、账号名（账号当前资料快照的昵称）。
2. 点赞 / 评论的值状态：评论非 `value` 时显示 `—`，不显示 0。
3. 「观看」SHALL 在新标签页打开 `shareUrl`；`shareUrl` 为空或协议不是 `http` / `https` 时按钮置灰。链接 SHALL 带 `rel="noopener noreferrer"`。
4. 「AI分析」点击 SHALL 弹出提示「AI分析功能正在开发中」，不发请求、不写数据。

### R6 · 参与活动计划（v1 置灰）

1. 下拉 SHALL 显示置灰并提示「暂未开放」；不得显示任何假的活动计划名或合格徽标。
2. 读口 SHALL 为该筛选预留契约（design §6）；本切片内读口收到活动计划参数 SHALL 返回 `plan_filter_unavailable`，不得忽略参数。

### R7 · 不泄露

1. 读口与页面 SHALL NOT 返回专员姓名、手机号、门店名与编码、账号内部 ID、平台账号原始标识。
2. 「AI分析」需要的内容标识只用公开形态的 `contentId`（十进制字符串）。

## 6. 失败语义

| 场景 | 行为 |
|---|---|
| 无 `square.read` / 空范围 | 无权限态，读口抛授权错误，不出现计数 |
| 筛选值非法 | 「筛选条件无效」，不执行宽查询 |
| 封面签名失败 / 封面缺失 | 该卡片用占位，其余卡片正常；不整页失败 |
| `shareUrl` 空或协议不允许 | 「观看」置灰 |
| 数据库不可用 | 通用错误态，可重试；不显示过期数据 |
| 页码越界 | 夹到最后一页（沿用既有 `pageOf` 做法） |
